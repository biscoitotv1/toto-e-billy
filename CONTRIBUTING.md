# Contribuindo

## Estado atual

O repositório está em fase de documentação. Engine, código, dependências e
processo de build ainda estão **A DEFINIR**.

## Fluxo

1. Clone o repositório e crie uma branch descritiva a partir da branch padrão.
2. Instale dependências quando elas forem definidas.
3. Faça uma alteração pequena e atualize a documentação relacionada.
4. Execute os testes e verificações disponíveis (atualmente: **A DEFINIR**).
5. Abra um Pull Request usando o template do repositório.

Exemplo:

```bash
git clone <URL_DO_REPOSITORIO>
git checkout -b docs/minha-alteracao
```

## Commits

Use prefixos consistentes: `feat:`, `fix:`, `docs:`, `refactor:`, `test:` e
`chore:`.

## Pull Requests

Descreva o motivo e o escopo da alteração, liste testes executados e indique
explicitamente qualquer item ainda **A DEFINIR**.
