# Código de Conduta

## Compromisso

Este projeto busca um ambiente acolhedor, respeitoso e colaborativo para todas
as pessoas, independentemente de experiência, identidade ou origem.

## Comportamento esperado

Seja respeitoso, forneça críticas construtivas, assuma boa-fé e priorize a
colaboração.

## Comportamento inaceitável e aplicação

Assédio, discriminação, ameaças e exposição de informações privadas não são
aceitos. Para relatar uma situação, use o canal privado descrito em
`SECURITY.md` ou contate os mantenedores: **A DEFINIR**.
