# Segurança

## Reporte privado

O canal oficial para reportar vulnerabilidades é **A DEFINIR**. Não publique
detalhes exploráveis em Issues ou Pull Requests; até que um canal seja definido,
contate os mantenedores por um meio privado conhecido.

Inclua impacto, passos para reprodução e uma correção sugerida, sem credenciais
ou dados pessoais.

## Boas práticas

- Nunca versione senhas, tokens, chaves ou arquivos de configuração secretos.
- Revogue credenciais expostas imediatamente.
- Mantenha dependências e ferramentas atualizadas quando forem definidas.
- Registre correções de segurança no changelog sem revelar detalhes exploráveis.

Dependências, política de versões e suporte de segurança: **A DEFINIR**.
