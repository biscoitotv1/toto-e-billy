# Roadmap

O projeto ainda não possui implementação identificável. As tarefas abaixo são
marcos de planejamento, não funcionalidades concluídas.

## Fase 1 — Fundação

- [x] Criar estrutura inicial de documentação
- [ ] Definir engine, linguagem e plataformas
- [ ] Definir licença, equipe e canais de projeto
- [ ] Criar o projeto executável

## Fase 2 — Protótipo

- [ ] Definir loop principal e controles
- [ ] Implementar protótipo jogável
- [ ] Validar a direção inicial

## Fase 3 — Vertical Slice

- [ ] Definir escopo do slice
- [ ] Produzir arte, áudio e UX do slice
- [ ] Validar pipeline técnico

## Fase 4 — Alpha

- [ ] Implementar conteúdo principal definido no GDD
- [ ] Integrar save, configurações e testes

## Fase 5 — Beta

- [ ] Completar conteúdo planejado
- [ ] Executar testes de compatibilidade, performance e regressão

## Fase 6 — Release Candidate

- [ ] Fixar escopo e versão
- [ ] Validar builds e materiais de distribuição

## Fase 7 — Lançamento

- [ ] Definir lojas, preço e comunicação
- [ ] Publicar a versão aprovada

## Fase 8 — Pós-lançamento

- [ ] Definir suporte, patches e telemetria
- [ ] Planejar atualizações com base no feedback
